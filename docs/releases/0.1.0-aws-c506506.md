These payloads are encrypted for the supplied customer public key and verify
licences against the supplied vendor public key. Pulling an image alone does not
grant a software licence or provide activation. Obtain the matching customer
private key and signed service licences through the authorized operator; never
commit or publish them. No key or licence contents are in this manifest.

The same image packaging passed local cold/warm health tests with disposable test
activation material, and rejected a tampered licence. The published release uses
the supplied real public keys; its AWS activation and end-to-end weather acceptance
have not yet been run. No AWS resources were created by this publication.

For Lambda, import each image into private ECR in the same region as the function
(Paris for the current template), verify the imported digest and use its ECR URI
in the image template. Store the activation material in private versioned S3, with
only exact-object read permission for each service role. Docker Hub references do
not go directly into Lambda's `ImageUri` parameter.

This is an initial image release, not a complete AWS-tested customer installer or
an approved Marketplace product. Deployment/cleanup acceptance, complete image
costing and Marketplace fulfillment remain pending. A separately purchased source
licence can permit builds without encryption under that agreement.
